# ALGORITHM DESIGN PROJECTS

## Algorithms, Flowcharts, Pseudocode & Sample Outputs

### Project Description
This project contains 10 real-world problem statements. Each question is designed using algorithms, flowcharts, pseudocode, and sample outputs.

## Questions

1. **University Scholarship Allocation**  
   Evaluates students based on aggregate marks, subject marks, attendance, and family income.

2. **Progressive Electricity Billing**  
   Calculates electricity bills using consumption slabs, fixed charges, surcharges, and rebates.

3. **Hospital Billing and Patient Classification**  
   Calculates consultation, diagnostic, and treatment charges with concessions and payment status.

4. **Employee Payroll and Deduction Analysis**  
   Calculates employee salaries, allowances, overtime, deductions, and net pay.

5. **Multi-Plan Telecommunications Cost Optimization**  
   Compares mobile plans based on usage, validity, excess charges, and budget.

6. **Railway Fare and Reservation Calculator**  
   Calculates railway fares based on distance, travel class, passenger age, and concessions.

7. **Retail Billing with Multiple Discount Rules**  
   Generates customer bills using product prices, quantities, discounts, and taxes.

8. **Manufacturing Cost and Profitability Analysis**  
   Calculates production costs, material costs, labour, wastage, revenue, and profit.

9. **Multi-Currency Travel Budget Analysis**  
   Converts travel expenses into Indian Rupees and compares spending with the budget.

10. **Campus Event Financial Planning**  
    Calculates event expenses, sponsorship, registration fees, and break-even registrations.
